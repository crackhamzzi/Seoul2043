# 서울 2043 PV 원본 사이트 통합 디자인

## 목적

별도 프로토타입에서 완성한 서울 2043 PV를 원본 React 사이트의 진입 화면에 통합한다. 기존 복합 버튼은 외형을 유지한 채 `PV 확인`과 `ENTER` 두 동작으로 분리한다. PV 종료 후에는 다시 진입 화면으로 돌아가지 않고 기존 `ENTER` 동작을 자동 실행해 본문 사이트로 자연스럽게 연결한다.

- 원격 저장소는 `https://github.com/crackhamzzi/Seoul2043.git`이다.
- 구현 브랜치는 `codex/pv-integration`이다.
- GitHub Pages의 `/Seoul2043/` 하위 경로에서 모든 이미지와 스크립트가 정상 로드되어야 한다.
- 현재 Vinext 빌드와 `.github/workflows/pages.yml` 배포 구조를 유지한다.

## 현재 진입 버튼

현재 `app/page.tsx`의 진입 화면에는 하나의 `.enter-button`이 있으며, 내부에 `기록 열람`과 `ENTER`가 함께 표시된다. 버튼 전체를 클릭하면 `setEntered(true)`가 실행되고 720ms 후 진입 화면이 숨겨진다.

## 버튼 통합 디자인

- 기존 버튼의 전체 크기, 테두리, 청록색 강조, 호버 분위기는 유지한다.
- 하나의 버튼을 시각적으로 연결된 두 개의 실제 버튼으로 분리한다.
- 왼쪽 버튼:
  - 표시: `PV 확인`
  - 동작: 전체화면 PV 오버레이를 연다.
  - 본문 진입 상태는 아직 변경하지 않는다.
- 오른쪽 버튼:
  - 표시: `ENTER`
  - 동작: 현재와 동일한 `setEntered(true)` 흐름을 실행한다.
- 키보드 사용자는 각 버튼을 독립적으로 포커스하고 실행할 수 있어야 한다.

## PV 오버레이

- 같은 페이지 안에 고정형 React 오버레이로 구현한다.
- 별도 `/pv` 라우트나 새 창을 사용하지 않는다.
- 진입 화면과 본문 사이트보다 높은 레이어에 표시한다.
- PV가 열려 있는 동안 문서 스크롤을 잠근다.
- 재생 중 `SOUND`, `SKIP`, `닫기` 제어를 제공한다.
- `닫기` 또는 Escape는 PV를 취소하고 기존 진입 화면으로 돌아간다. 이 경우 `ENTER` 상태를 변경하지 않는다.
- `SKIP`은 마지막 독백·로고 전환으로 이동하며 자동 본문 진입 흐름은 유지한다.
- `prefers-reduced-motion`에서는 강한 플래시, 화면 찢김, 빠른 노이즈를 줄인다.

## PV 장면 구성

- 별도 프로토타입의 장면 순서와 타이밍을 원본 사이트에서 재현한다.
- 사이버홀딩스 명령 → 시민과 안드로이드의 동시 멸시 → 하나의 질문 → 붉은 시스템 `왜?` 폭주 순서를 유지한다.
- 하나 절규 장면은 제공된 `하나절규.png` 사본을 배경으로 사용한다.
- `왜?`는 104개의 붉은 시스템 모노스페이스 글자로 표시한다.
- `ERROR`, `SOURCE`, 진단 코드 등 새로운 오류 문구를 추가하지 않는다.

## 엔딩과 자동 진입

- 기존 `THE ARCHIVE IS OPEN` 문구를 사용하지 않는다.
- 기존 텍스트 `SEOUL 2043` 타이틀을 사용하지 않는다.
- 붉은 `왜?` 장면이 끝나면 암전 후 다음 문장을 순차 타이핑한다.
  - `저도 모르겠습니다.`
  - `누가… 정답을 알려주세요.`
- 두 번째 문장이 끝나는 즉시 두 문장은 수평 노이즈로 깨지며 사라진다.
- 같은 순간 제공된 투명 서울 2043 로고가 중앙에 노이즈와 함께 등장한다.
- 로고가 중앙에 남아 있는 동안 부모 페이지의 기존 `ENTER` 흐름을 실행한다.
- 기존 진입 화면은 720ms 전환을 거쳐 사라지고 본문 사이트가 로고 뒤에서 나타난다.
- 본문이 열린 뒤 중앙 PV 로고는 약 1초 동안 남았다가 짧은 노이즈와 함께 사라진다.
- PV 오버레이가 제거된 뒤 사용자는 이미 진입된 본문 홈 화면을 보게 된다.
- 마지막에는 별도의 `닫기`나 `다시 재생`을 요구하지 않는다.

## 상태 흐름

```text
entry
  ├─ ENTER ───────────────────────────────> entered site
  └─ PV 확인 -> playing
                  ├─ cancel / Escape ─────> entry
                  ├─ skip ────────────────> final monologue
                  └─ natural end
                        -> final monologue
                        -> logo noise reveal
                        -> run existing ENTER transition
                        -> entered site behind logo
                        -> logo noise exit
                        -> close PV overlay
```

## 오류·정리 처리

- 이미지 로드 실패 시 장면은 검은 배경과 텍스트만으로 계속 진행한다.
- Web Audio 생성이 실패하거나 브라우저가 차단해도 무음으로 계속 재생한다.
- PV 취소, 완료, 컴포넌트 해제 시 예약 타이머와 `requestAnimationFrame`을 모두 정리한다.
- 오디오 컨텍스트는 예외를 삼키며 안전하게 닫는다.
- PV 중복 실행을 막고 완료 콜백은 한 번만 호출한다.

## 검증 기준

- 첫 화면에 `PV 확인`과 `ENTER`가 별도 버튼으로 보인다.
- `ENTER`만 누르면 PV 없이 기존 사이트가 동일하게 열린다.
- `PV 확인`을 누르면 전체화면 PV가 시작된다.
- 취소하면 진입 화면으로 복귀하고 본문은 열리지 않는다.
- 기존 명령·멸시·질문·붉은 `왜?` 장면이 재생된다.
- 엔딩에 두 한국어 문장이 정확한 순서로 타이핑된다.
- `THE ARCHIVE IS OPEN`과 텍스트 제목 `SEOUL 2043`은 PV 엔딩에 나타나지 않는다.
- 문장 직후 제공된 투명 로고가 노이즈로 등장한다.
- 로고 뒤에서 기존 본문 홈 화면이 열리고, 로고가 사라진 뒤 본문 조작이 가능하다.
- 직접 `ENTER`와 PV 완료 모두 같은 진입 완료 상태를 만든다.
- GitHub Pages 하위 경로에서 두 신규 이미지가 정상 로드된다.
- `npm test`와 `npm run lint`가 통과한다.
- 데스크톱과 모바일에서 PV가 화면을 벗어나지 않는다.
