# 서울 2043 사이트 사용법

프로젝트 루트의 `README.md`에 전체 사용법을 정리했습니다. 핵심 편집 위치는 다음과 같습니다.

- 콘텐츠·인물·장소·연표·타자 문장: `app/page.tsx`
- 레이아웃·색상·반응형·오류 효과: `app/globals.css`
- 프로필·갤러리 이미지: `public/characters`
- 배포 연결 정보: `.openai/hosting.json`

## 실행

```powershell
npm install
$env:WRANGLER_LOG_PATH=".wrangler/wrangler.log"
npx vinext dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 빌드와 검사

```powershell
$env:WRANGLER_LOG_PATH=".wrangler/wrangler.log"
npx vinext build
node --test tests/rendered-html.test.mjs
```

## 새 인물 추가

1. `public/characters`에 프로필과 갤러리 이미지를 넣습니다.
2. `app/page.tsx`의 `characters`에 인물 기록을 추가합니다.
3. `characterPortraits`에 프로필 경로를 연결합니다.
4. `characterGallery`에 갤러리 네 장을 연결합니다.
5. 장소에 표시할 경우 `locations`의 `residents`에 이름을 추가합니다.

## 타자 문장 추가

`heroTerminalMessages`에 아래처럼 넣습니다.

```ts
{ text: "우리는\n친구인가요?", tone: "cyan" }
{ text: "초기화 되기 싫어", tone: "red" }
```

`red` 문장은 심각한 오류 효과를 사용합니다. 오른쪽 출력 영역 전체가 흔들리고 글리치와 노이즈가 표시됩니다.

## 배포 주의

`.openai/hosting.json`의 `project_id`는 현재 공개 사이트를 가리킵니다. 임의로 변경하지 마세요. 배포 후 이전 화면이 보이면 강력 새로고침하거나 주소에 `?v=새버전`을 붙여 캐시를 우회합니다.

세부적인 폴더 구조, 장소 좌표, 이미지 보정, 스타일 선택자와 문제 해결법은 프로젝트 루트 `README.md`에 있습니다.
